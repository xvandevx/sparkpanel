# SparkPanel

**Headless CMS для мультидоменных и региональных сайтов, которая ставится на свой сервер.**
Структура контента настраивается в самой панели — без кода и перезапусков, — а сайт
забирает данные через REST API. ИИ-ассистенты работают с контентом через MCP.

[English version](README.md)

> **Ранняя версия.** API и настройки между версиями могут меняться — см.
> [«Планы»](#планы).

## Чем отличается

- **Структура контента меняется из интерфейса.** Свойства добавляются к любому списку
  прямо в работающей панели: строка, число, текст, HTML (визуально или кодом), список,
  файл, изображение, таблица, привязки к записям, к типам контента и к вариантам
  другого списка. Ни файлов схемы, ни пересборки, ни деплоя.
- **Мультидоменные значения.** Одна запись — много сайтов: у свойства общее значение
  для всех доменов, исключение «для всех, кроме msk» и своё значение для группы
  поддоменов (`ekb.example.ru`, `spb.example.ru`). API отдаёт значение для запрошенного
  домена. Записи под каждый город не дублируются.
- **Готовые разделы.** Дерево страниц, типы контента с элементами, товары с категориями,
  медиатека с разделами и S3-хранилищами, пользователи и роли, домены.
- **Деревья везде.** Любой список может быть вложенным; привязки выбираются деревом,
  галочкой на всю ветку.
- **Безопасная редактура.** Черновики рядом с опубликованным, журнал изменений
  у каждого списка (с автором), резервные копии списка и всего сайта, восстановление
  в один клик.
- **REST API для сайта.** `/api/v1` по ключу: страницы, поиск, фильтры по свойствам,
  фасеты с количеством, `expand` для связанных записей, значения по домену.
  Спецификация OpenAPI собирается из настроек списков — документация всегда актуальна.
- **Встроенный MCP-сервер.** Claude, Cursor или любой MCP-клиент подключаются личным
  токеном: ассистент читает и правит контент (и черновики) ровно с вашими правами,
  каждая его правка подписана в журнале.

## Быстрый старт

Нужен Docker с Compose.

```bash
git clone https://github.com/xvandevx/sparkpanel.git
cd sparkpanel/webSite/headless
cp .env.example .env        # заменить все значения: openssl rand -hex 32
docker compose up -d --build
```

Откройте http://localhost:3000 — первым входом заводится главный администратор.

Панель и API — один образ на одном порту, рядом Postgres и MinIO. Для HTTPS поставьте
перед панелью любой прокси (Caddy, Traefik, nginx).
Подробности — [webSite/headless/README.md](webSite/headless/README.md).
