# scripts

Вспомогательные скрипты локальной разработки.

**Полная документация:** [../CLAUDE.md](../CLAUDE.md) · **прод:** [../prod/README.md](../prod/README.md)

| Файл | Назначение |
|------|------------|
| `dev.sh` | Весь стек одной командой: docker (nginx :3400 + postgres :3403) → backend :3402 → frontend :3401 |
| `stop.sh` | Погасить всё: dev-серверы (по портам, не по имени процесса) + контейнеры |
| `seed/` | Демо-данные «Фаркоп.ру» для локальной панели — см. ниже |

## Демо-данные (`seed/`)

```bash
node scripts/seed/index.mjs              # все разделы по порядку
node scripts/seed/index.mjs pages forms  # только указанные
```

Наполняет **поднятый** локальный стек через API (как браузер, через nginx :3400): по 5–10
записей в каждом разделе, дерево страниц, медиатеку со сгенерированными файлами и
[свойства записей](../../docs/list-settings.md) всех типов у каждого списка. Запуск
идемпотентный — записи ищутся по коду, email, имени хоста, повтор ничего не дублирует.
Существующие данные не удаляются и не переписываются: свойства дописываются к
уже заведённым, значения — сливаются.

- Порядок модулей — в `index.mjs`: сначала записи разделов, потом свойства (они
  ссылаются на файлы и записи других разделов).
- Токен root `token.mjs` подписывает сам ключом из `backend/.env` и берёт root из
  локальной базы — **только для локальной разработки**. Свой токен — в `SEED_TOKEN`,
  другой адрес API — в `SEED_API`.
- Тестовые пароли демо-пользователей лежат в `seed/users.mjs`.

Приложение открывается на **http://localhost:3400** — всё идёт через nginx, как на проде.
Открывать `:3401` напрямую нельзя: сломается Google OAuth (см. «один origin» в `CLAUDE.md`).
Порты стека — `340x`: 4000/4001/4010/4432 заняты focuzy, 3000 — ещё одним проектом.

**Slash-команды Claude Code:** `/dev-up`, `/dev-stop`, `/dev-front`, `/dev-back`, `/deploy`, `/ssl`
(файлы — в `.claude/commands/` в корне репозитория).
