# Каркас админки и навигация

Оболочка приложения: левое меню с разделами и учётной записью внизу, область содержимого.
Шапки с названием раздела у приложения нет: **название стоит на самом экране** — заголовком
над содержимым (`components/ui/PageTitle.tsx`).

## Разделы

Список разделов — **один** на всю систему, в `webSite/frontend/config/navigation.ts`.
Из него строятся меню, карточки «Главной» и подсветка активного пункта.

| Раздел | Маршрут | Состояние |
|--------|---------|-----------|
| Главная | `/admin` | приветствие и карточки переходов |
| Страницы | `/admin/pages` | дерево страниц сайта ([`docs/pages.md`](pages.md)) |
| Товары → Категории | `/admin/products/categories` | дерево категорий товаров ([`docs/products.md`](products.md)) |
| Товары → Товары | `/admin/products` | товары; категории — системным свойством ([`docs/products.md`](products.md)) |
| Инфоблоки | `/admin/infoblocks` | типы, инфоблоки и их записи — три уровня ([`docs/infoblocks.md`](infoblocks.md)) |
| Почта | `/admin/mail` | заглушка |
| Пользователи → Пользователи | `/admin/users` | учётные записи панели ([`docs/users.md`](users.md)) |
| Пользователи → Роли | `/admin/users/roles` | роли пользователей ([`docs/users.md`](users.md)) |

Новый раздел добавляется в `config/navigation.ts` и файлом страницы в `pages/admin/`.

## Состав

| Компонент | Назначение |
|-----------|-----------|
| `components/layout/AdminLayout.tsx` | гард доступа: индикатор → экран входа/настройки → приложение |
| `components/layout/AppShell.tsx` | каркас: меню + содержимое |
| `components/layout/sidebar/Sidebar.tsx` | левое меню, сворачивается |
| `components/layout/sidebar/SidebarUser.tsx` | учётная запись внизу меню: кто вошёл и выход |
| `logic/navigation/useNavigation.ts` | активный раздел и переходы |
| `components/ui/BrandMark.tsx` | логотип SparkPanel: искра + название (исходник — `brand/sparkpanel-mark.svg`) |
| `components/ui/VantaHalo.tsx` | анимированный фон экрана входа |
| `components/ui/PageTitle.tsx` | заголовок раздела над его содержимым — один на все экраны |

Активным считается самый длинный подходящий путь: на `/admin/users` подсвечивается
«Пользователи», а не «Главная». Сравнивается `router.asPath`, а не `pathname`: у страницы
с параметром (`/admin/infoblocks/[sectionId]`) `pathname` это шаблон, по которому не понять,
какой подпункт подсветить.

Пункт меню может разворачиваться в **подменю**. Статическое подменю — `children` у раздела
в `config/navigation.ts`: такой пункт только **группа** (`isGroup`), своей страницы у него
нет, ключ — имя группы, а не путь («Пользователи» → «Пользователи», «Роли»). Группа раскрыта,
когда открыт любой её подпункт; карточка группы на «Главной» ведёт на первый подпункт
(`sectionPath`). Подменю из данных — `childrenSource` у раздела, перечень источников —
в `useNavigation`. Сейчас он один: «Контент» раскрывается в **дерево типов контента**
с той же вложенностью, что в их списке (`logic/contents/useContentsMenu.ts`;
тип ведёт на `/admin/contents/<id>`). Такой пункт и ведёт на свою страницу (все типы),
и раскрывается: antd у пункта с подменю `onClick` не зовёт, по названию переходим сами.
Типов нет — пункт без подменю. Типы лежат в ячейке редактора контента, поэтому добавленный
или переименованный в списке тип появляется в меню сам; перечитываются они при показе меню.

**Заголовок раздела.** У экранов на редакторе контента это название открытого пункта
меню (`contentEditorNew/header/ListTitle.tsx`): заголовок и меню не расходятся, а имени
списка в окне настроек нет. Остальные
экраны называют себя сами тем же `PageTitle`: «Настройки сайта», раздел файлов — своим
именем под крошками. Где название уже есть (список в шторке с заголовком), заголовок
списка выключают (`isTitleHidden`).

Учётная запись живёт **внизу левого меню**, а не в шапке: имя, роль и «Завершить сеанс»
по клику. В свёрнутом меню остаётся только аватар, имя и роль показывает подсказка.

## Оформление

Ant Design v6, **стандартная тема**: светлый алгоритм, фирменный синий, дефолтные размеры.
Левое меню — штатная связка antd: `Layout.Sider` по умолчанию тёмный, `Menu` в нём с
`theme="dark"`, содержимое светлое. Единственное место настройки цветов и скруглений —
`webSite/frontend/config/theme.ts` (там же единственное отклонение от стандарта: фон шапки,
иначе она была бы тёмной на светлом содержимом). Локальные стили в компонентах — только раскладка.

## Правила

- Страницы (`pages/admin/*.tsx`) содержат **только композицию**: гард + экран.
- Компоненты берут данные из хуков `logic/`, а не из redux напрямую.
- Ant Design в этой связке требует двух настроек, без которых ломается SSR:
  `transpilePackages` в `next.config.js` и сборка стилей в `pages/_document.tsx`.
