# Настройки

Пункт «Настройки» — последний в левом меню, раскрывается в подпункты:
«Настройки сайта» (`/admin/settings`), «Хранилища» (`/admin/settings/storages`), «Домены»
(`/admin/settings/domains`, подробности — [`domains.md`](domains.md)), «API»
(`/admin/settings/api`, только главному администратору — ключи и документация внешнего
API, [`external-api.md`](external-api.md)), «MCP» (`/admin/settings/mcp`, всем — подключение
ИИ-ассистентов, личные токены и журнал вызовов, [`mcp.md`](mcp.md)) и «Резервные копии»
(`/admin/settings/backups`, только главному администратору — копии всей базы,
[`backups.md`](backups.md#копия-всего-сайта)). Хранилища и домены —
списки со своими карточками, поэтому отдельные страницы, а не вкладки: общий черновик
и кнопка «Сохранить» к ним не относятся.

«Настройки сайта» — одна вкладка «Общие»: название сайта, хранилище — куда
загружаются новые файлы: во встроенное (папка на диске рядом с панелью, по умолчанию) или
в одно из внешних S3-совместимых, — и логотип панели. Внешних хранилищ сколько угодно,
они заводятся в подпункте «Хранилища».

**Логотип** — свой знак компании вместо SparkPanel в левом меню и на экране входа
(и первичной настройки). Нет своего — панель рисует SparkPanel.

Настройки, хранилища и домены **общие на весь сайт**: владельца у строк нет, все
пользователи панели видят и правят одно и то же.

## Модель данных

### `settings` — параметры сайта

**Строка на настройку**: ключ и значение. Колонки под каждую настройку нет — новая
настройка это новый ключ, а не миграция.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `SERIAL` | |
| `key` | `STRING(64)` | ключ настройки, уникальный (`settings_key`) |
| `value` | `TEXT` | значение |

Ключи и значения по умолчанию — `SETTINGS_DEFAULTS` в `backend/src/settings/settings-values.ts`:

| Ключ | По умолчанию | Что значит |
|------|--------------|-----------|
| `siteName` | пусто | название сайта |
| `storageId` | пусто | хранилище для новых файлов: номер из `infoblock_storages`; пусто — встроенное |
| `logo` | пусто | логотип панели — картинка data URI (`data:image/png;base64,…`); пусто — SparkPanel |

Нет строки — у настройки значение по умолчанию. Строки заводятся при сохранении,
пишутся только изменённые ключи (upsert по `key`). Ключ, которого нет в списке,
не читается и не пишется.

**Логотип лежит в самой настройке, а не в хранилище файлов** (`settings/logo.ts`):
копия сайта уносит базу без файлов, и логотип из хранилища после восстановления пропал
бы; выбранное для файлов хранилище к логотипу панели отношения не имеет. Картинка —
PNG, JPEG, WebP, GIF или SVG до 512 КБ, иначе `PATCH` отвечает 400. Наружу data URI
не отдаётся — только адрес картинки `logoUrl`.

### `infoblock_storages` — внешние хранилища

Модуль `backend/src/infoblocks/storages/`: хранилища — список редактора контента
(ключ `storages`), а все такие списки живут в `infoblocks/`, хотя показывается этот
в настройках.

| Поле | Тип | Описание |
|------|-----|----------|
| `id` | `SERIAL` | номер хранилища — его хранит `storageId` у настроек и у файлов |
| `name` | `STRING` | название в выборе |
| `isActive` | `BOOLEAN`, по умолчанию `true` | неактивное не выбрать для новых файлов; лежащие в нём открываются |
| `sort` | `INTEGER`, по умолчанию 500 | «Сортировка» |

**Подключение — не колонки, а системные свойства списка `storages`**
(`STORAGE_PROPERTY` в `infoblocks/settings/properties/system-properties.ts`), значения —
в `infoblock_values`, как у любого свойства:

| Код | Название | Описание |
|-----|----------|----------|
| `endpoint` | «Адрес S3 API» | `https://storage.yandexcloud.net`; обязательное |
| `region` | «Регион» | пусто — `us-east-1` |
| `bucket` | «Бакет» | обязательное |
| `accessKey` | «Ключ доступа» | обязательное |
| `secretKey` | «Секретный ключ» | скрытое (`isHidden`) — **наружу не отдаётся** никаким маршрутом |
| `publicUrl` | «Публичный адрес» | адрес, по которому файлы видны на сайте (CDN, домен бакета); пусто — адрес/бакет |

Свойствами, а не колонками — потому что так карточка хранилища это обычная карточка
редактора, а секрет закрыт общим правилом скрытых свойств
([`infoblock-settings.md`](infoblock-settings.md#скрытые-свойства)). Список общий
(`isShared`): настройки и значения лежат под владельцем `0`, по ним сервер ходит в S3
за любого пользователя.

Встроенного хранилища в таблице нет: оно одно, его адрес и ключи — в env бэкенда
([`files.md`](files.md#настройки)). Ключи внешних лежат в базе открытым текстом: базу
с ними надо беречь так же, как `.env`.

## API

Все маршруты, кроме двух для логотипа, требуют авторизации; настройки и хранилища
при этом одни на всех.

| Метод | Путь | Что делает |
|-------|------|-----------|
| `GET` | `/api/settings` | `{ siteName, storageId, logoUrl }`; `storageId: null` — встроенное, `logoUrl` пусто — SparkPanel |
| `PATCH` | `/api/settings` | только присланное; `storageId: null` — выбрать встроенное. Внешнее хранилище должно существовать (404), быть включённым (400 «Хранилище выключено»), заполненным и отвечать (400). `logo` — картинка data URI, `null` — вернуть SparkPanel; не та картинка или больше 512 КБ — 400 |
| `GET` | `/api/settings/brand` | **без входа**: `{ siteName, logoUrl }` — чем подписан экран входа |
| `GET` | `/api/settings/logo` | **без входа**: картинка логотипа, своего нет — 404 |
| `GET` | `/api/infoblocks/storages` | внешние хранилища: `{ id, name, isActive, sort, filesCount, isBlocked }`, порядок — `sort`, название, номер |
| `POST` | `/api/infoblocks/storages` | добавить: `{ name, isActive?, sort? }` |
| `PATCH` | `/api/infoblocks/storages/:id` | поправить присланное (`name`, `isActive`, `sort`); выключить выбранное для новых файлов — 409 |
| `DELETE` | `/api/infoblocks/storages/:id` | удалить вместе со значениями свойств; 409 — выбрано для новых файлов или в нём лежат файлы |
| `PATCH` | `/api/infoblocks/storages/values/:id` | подключение — значения свойств, общий маршрут значений ([`infoblock-settings.md`](infoblock-settings.md#api)) |

`logoUrl` — `/api/settings/logo?v=<версия>`, версия — хэш картинки. С ней ответ
кэшируется навсегда (`immutable`): сменили логотип — сменился адрес; без версии или
со старой — `no-cache`. Картинка отдаётся с `X-Content-Type-Options: nosniff`
и `Content-Security-Policy: … sandbox`, SVG — вложением (`file-disposition.ts`):
`<img>` рисует его, а открытый в адресной строке он не выполнится как страница панели.

Подключения в `StorageDto` нет: карточка шлёт его вторым запросом, значениями свойств.
Проверяет его раздел хранилищ при сохранении значений (`StoragesService.checkConnection`,
проверка значений раздела): публичный адрес — только `http(s)://`; тронули адрес, регион,
бакет или ключи — адрес S3 API (`http(s)://`), бакет и оба ключа должны быть заполнены
(секрет, если его не прислали, берётся сохранённый), и хранилище должно ответить. Проверка —
запрос `HeadBucket`, до 10 секунд. Не ответило — 400 с причиной («нет доступа к бакету —
проверьте ключи», «бакет не найден», «проверьте адрес и регион»), и значения
не сохраняются. Само хранилище заводится раньше, первым запросом: без подключения его
просто не выбрать для новых файлов.

## Интерфейс

Экран — `components/settings/` (`SettingsScreen`, вкладка `SiteFields`;
хранилища и домены — отдельные экраны `StoragesScreen` и `DomainsScreen`), логика —
`logic/settings/`. Форма горизонтальная, та же раскладка, что в редакторе контента (`FORM_LAYOUT`).

- Черновик один на название, хранилище и логотип; «Отменить» и «Сохранить» — справа
  от вкладок, неактивны, пока правок нет. Уходит только изменённое.
- «Логотип» — «Загрузить»; когда логотип выбран — ещё превью на фоне и шириной левого
  меню (`Layout.Sider`) и «Убрать». Не выбран — превью нет вовсе: SparkPanel в нём
  читался бы как загруженный логотип. Файл не уходит сам: он проверяется (тип, 512 КБ —
  `logic/settings/logoFile.ts`), читается в data URI и ложится в черновик; сохраняется
  общим «Сохранить». В черновике — адрес сохранённого, data URI нового или пусто,
  все три годятся в `<img src>`.
- Логотип в меню и на экране входа рисует `BrandMark` (`components/ui/`): с `logoUrl` —
  картинкой высотой 36 px (в свёрнутом меню ужимается по ширине), без — знак и название
  SparkPanel. Откуда его взять, говорит `useBrand` (`logic/settings/`): `GET
  /api/settings/brand` один раз за сеанс, в стор — `state.settings.brand`. Пока ответа
  нет, логотипа нет вовсе (место под него держится) — иначе SparkPanel мелькал бы перед
  своим; сервер не ответил — SparkPanel. Сохранили название или логотип — `brand`
  перечитывается, меню меняется сразу. Подпись внизу экрана входа «SparkPanel · система
  администрирования» остаётся.
- Выбор «Хранилище» — «Встроенное (папка панели)» и внешние по названию; выключенное
  показано в выборе закрытым, с пометкой «(выключено)» (`useStorageOptions`). Рядом
  кнопка «Хранилища» — переход на страницу хранилищ.
- «Хранилища» — список на [редакторе контента](../webSite/frontend/CLAUDE.md), заголовок —
  название пункта меню; только кнопки «Добавить хранилище» и «Экспорт» (без журнала
  и настроек списка), колонки
  «Хранилище», «Файлов», «Активность», «Сортировка». Карточка хранилища — тоже шторка
  редактора: «Название», «Активность», «Сортировка» и системные свойства подключения;
  секретный ключ — поле скрытого свойства: набирается скрыто, всегда пустое, пустое —
  «оставить прежний». Выбранное хранилище и хранилище с файлами показаны с замком,
  без «Удалить».
- Добавили хранилище на его экране — оно появляется в выборе; сохранили другой выбор —
  список хранилищ перечитывается, и замок переезжает.

## Правила и ограничения

- Переключение хранилища касается **только новых** файлов: у загруженного хранилище
  и адрес запомнены ([`files.md`](files.md)).
- Бакет внешнего хранилища панель не создаёт и прав на нём не меняет: открыть чтение
  файлов по публичному адресу — забота владельца хранилища.
- Бэкенд сам ходит по адресу хранилища — значит, любой пользователь панели может
  заставить его постучаться на произвольный `http(s)`-адрес. Ограничений по сетям нет.
- Настройки и хранилища общие: правка одного пользователя панели видна всем. Править
  их может любой вошедший — отдельного права нет.
- Изменения настроек и хранилищ в журнал (`history`) не пишутся.
- Логотип и название сайта видны без входа (`/api/settings/brand`): это то, что и так
  показывает экран входа. Остальные настройки — только вошедшим.
- Логотип рисуется на тёмном фоне меню и экрана входа — нужен светлый вариант знака.

## Настройки

Переменных окружения у модуля нет; встроенное хранилище настраивается env бэкенда —
[`files.md`](files.md#настройки).
