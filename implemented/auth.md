# Доступ и учётные записи

## 12.09.2026 — вход по email/паролю и первичная настройка

**Что сделано**

- Бэкенд: модули `auth` и `users` — `GET/POST /api/auth/setup`, `POST /api/auth/login`,
  `GET /api/auth/me`; глобальный `AuthGuard` с декоратором `@Public()`; bcrypt-хэширование;
  таблица `users` с ролями `root`/`user`.
- Фронт: экран `/admin` с тремя состояниями (проверка доступа / первичная настройка / вход),
  хранение токена в cookie, восстановление сеанса, выход.

**Ключевые решения**

- **Регистрации нет, администратор не задаётся через env.** Изначально стартовый админ
  создавался из `ADMIN_EMAIL`/`ADMIN_PASSWORD`; отказались — два механизма создания root это
  способ случайно оставить на проде учётку с паролем из примера конфига. Остался один путь:
  экран первичной настройки, эндпоинт закрывается после создания (409).
- **Гарантия единственного root — частичный уникальный индекс** `UNIQUE (role) WHERE role='root'`.
  Проверки `hasRoot()` в сервисе недостаточно: между SELECT и INSERT пролезает параллельный
  запрос, а эндпоинт публичный.
- **Одинаковый текст ошибки** на «нет пользователя» и «неверный пароль» — чтобы форма не
  работала перебором существующих адресов.
- **`UserDto` вместо отдачи модели** — хэш пароля не может утечь в ответ по невнимательности.
- **`JwtModule.registerAsync`**: синхронный `register` читает `process.env` при импорте модуля,
  раньше чем `ConfigModule` загрузит `.env`, и логин падает с `secretOrPrivateKey must have a value`.

**Не сделано**

- Google OAuth — задел в nginx/prod-конфигах остался, код не подключён.
- Роли и права (RBAC), приглашения администраторов, сброс пароля — отдельная задача.

**Проверено**

- curl-матрица: нет токена, битый токен, невалидное тело, повторная настройка (409),
  неверный пароль (401), успешный вход и `/me`.
- В браузере: пустая база → экран настройки → валидация (короткий пароль, несовпадение) →
  создание администратора → панель → перезагрузка (сеанс восстановлен) → выход → показывается
  вход, а не настройка → неверный пароль → верный вход.
