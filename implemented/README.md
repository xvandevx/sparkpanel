# implemented — реализованный функционал

Журнал сделанного. Эту папку веду я по факту завершения работы: один файл на модуль,
дополняется сверху вниз по мере доработок.

Отвечает на вопрос «**что и почему сделано**», а не «как этим пользоваться» —
пользовательская часть живёт в `docs/`.

## Формат файла

```markdown
# <Модуль>

## <дата> — <краткая суть>

**Что сделано** — перечень: эндпоинты, таблицы, экраны.
**Ключевые решения** — что выбрано и почему, какие альтернативы отклонены.
**Отступления от задания** — что сделано иначе, чем в `planned/`, и по какой причине.
**Не сделано** — сознательно вынесенное за рамки, с причиной.
**Проверено** — чем подтверждено: тесты, ручные сценарии, что именно прогонялось.
```

Здесь же фиксируются допущения, принятые при нехватке требований, — чтобы через полгода
было понятно, почему система ведёт себя именно так.
